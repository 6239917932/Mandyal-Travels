# Language and currency governance

The shared catalogue starts with English and Hindi India locales and INR, USD, EUR, and GBP display currencies. Monetary values remain integer minor units with an explicit ISO currency; localization changes presentation, never the stored quote or settlement amount.

Before exposing a language, all transactional, policy, accessibility, error, email, SMS, invoice, and support content requires professional translation and review. Currency conversion requires a contracted rate source, timestamped rates, spread/rounding policy, customer disclosure, settlement rules, caching limits, and reconciliation; the portal must not imply live conversion until that provider is active.
