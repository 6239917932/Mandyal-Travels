# iOS application delivery

The versioned APIs, scoped authentication, correlation IDs, responsive portal, hosted payment boundary, and deep-link-ready notifications provide the iOS backend contract. A native iOS release remains a separately signed client artifact.

Delivery requires an approved bundle ID, supported iOS policy, Keychain token storage, MFA/session flows, accessibility, offline/error states, universal links, APNs, hosted payment handoff, privacy manifests and nutrition labels, analytics consent, crash reporting, device testing, App Attest/security review, certificates/profiles, signed archives, App Store Connect review, phased rollout, and rollback ownership. No iOS app is represented as published until App Review approval succeeds.
