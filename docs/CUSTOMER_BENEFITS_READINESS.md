# Customer benefits readiness

`/account/benefits` is a read-only customer view of existing loyalty-ledger and referral-readiness records. Every query is scoped to the authenticated customer user ID. The page does not return database IDs, ledger references, or referral codes and does not create an account, balance, ledger entry, or referral record.

The programme is not launched. Points cannot be earned or redeemed, the wallet cannot be funded, spent, transferred, or withdrawn, and referrals cannot be shared or rewarded. Persisted values are displayed only as non-spendable system records.

Activation remains blocked until approved earning, redemption, expiry, refund-reversal, negative-balance, liability, reconciliation, fraud, self-referral, wallet legal/KYC, tax, statement, and customer-support policies are implemented and verified. Cashfree is not part of this readiness surface.
